## Описание
Проект содержит автоматизированные тесты для веб-приложения tellar Burgers
Убедитесь, что у вас установлены Chrome и Firefox


## Что проверяют тесты
1. Тесты авторизации (test_login.py)
1) Переход на страницу логина.
- Ввод почты и пароля.
- Успешная авторизация (проверка перехода на нужную страницу).

2. Восстановление пароля (test_password_recovery.py)
- Переход на страницу восстановления по ссылке.
- Ввод почты, клик по кнопке «Восстановить».
-  Проверка, что поле пароля становится активным при клике «показать/скрыть».

3. Личный кабинет (test_personal_account.py)
- Переход по кнопке «Личный кабинет».
- Переход в раздел «История заказов».
- Выход из аккаунта.

4. Основной функционал (test_main_functionality.py)
- Переход в конструктор.
- Переход в ленту заказов.
- Открытие деталей ингредиента.
- Закрытие всплывающего окна.
- Проверка увеличения счётчика при добавлении ингредиента.
- Оформление заказа авторизованным пользователем.

5. Лента заказов (test_order_feed.py)
- Открытие деталей заказа.
- Проверка отображения заказов из истории пользователя.
- Увеличение счётчика выполненных заказов (всего и за сегодня).
- Появление номера нового заказа в разделе «В работе».






## Установка

1. Склонируй проект:
git clone https://github.com/MariaVarfolomeeva/Diplom_2
cd Diplom_2
2. Установи зависимости
pip install -r requirements.txt
3. Запуск тестов 
pytest --alluredir=allure-results   
4. Оформление отчета 
allure serve allure-results
